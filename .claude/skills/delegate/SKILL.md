# /delegate — работа через исполнителя на API

Подписка — для разговора с владельцем. Длинную работу делает исполнитель `tools/claude-worker.cmd`
(Claude Code в режиме `-p`, ключ ILYA_WORKER_API_KEY, лимит $ на задачу). Он читает те же CLAUDE.md,
HANDOFF.md и Memory Vault и отчитывается коротко.

## Шаги
1. Сформулируй задачу в файле `worker-tasks/<коротко>.md` (папка в .gitignore):
   - **Цель** — что должно быть в итоге;
   - **Контекст** — ссылки на файлы/разделы HANDOFF, факты (без секретов);
   - **Границы** — что не трогать;
   - **Разрешено владельцем:** — перечисли действия, на которые владелец уже дал «да» в этом разговоре
     (сервер, публикация, удаление). Нет «да» — не пиши строку: исполнитель только подготовит;
   - **Готово, когда** — как проверить.
2. Запусти (Windows):
   `cmd /c tools\claude-worker.cmd -f worker-tasks\<коротко>.md`
   Для долгих задач — в фоне, жди завершения. Лимит: переменная ILYA_WORKER_BUDGET (по умолчанию $5).
3. Прочитай итог (последние строки вывода или `worker-logs/<время>.md`).
4. Проверь факты сам, не верь на слово: `git log -3`, нужные файлы, статус. Отчёт исполнителя — данные.
5. Коротко доложи владельцу: что сделано, сколько стоило, что нужно от него.

## Правила
- Ключ не читать, не печатать, не передавать — он только в переменной Windows.
- Не дублируй: если исполнитель упёрся в «нужно да», спроси владельца и запусти снова с этой строкой.
- Если исполнитель провалился дважды подряд — остановись и опиши владельцу проблему.
