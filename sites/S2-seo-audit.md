# S2. SEO-аудит granitline.ru и kub-lesa.ru

Дата измерений: 02.10.2026, 22:07–22:40 МСК. Только чтение публичных страниц (GET/HEAD), на сайтах ничего не менялось, формы не отправлялись.
Источники (локально, не в git, есть контакты сайтов): `sites/raw/locs-crawl.tsv` (все 398 URL из обеих карт сайта: код, время, title, H1, description, canonical, robots, типы микроразметки), `sites/raw/deep.txt`, `more.txt`, `links.txt`, `comp.txt`, `.tmp-direct/*.txt`. Скрипты: `sites/tools/seo_*.py`.
Чего нет: позиций, частот, трафика, данных Core Web Vitals, индексации. Для этого нужен доступ к Метрике, Вебмастеру и Вордстату.

## 1. Коротко

- Оба сайта собраны на Next.js, отдаются как статика (nginx, ответ 50–330 мс). Технически аккуратные: все 398 URL из sitemap отдают 200, canonical везде указывает на себя, дублей title/H1 нет, пустых H1 нет, у всех description от 116 символов, битых внутренних ссылок нет (проверено 106 + 192 уникальных ссылки), 404 настоящий, с `noindex`.
- **granitline.ru**: главная проблема коммерческая, а не техническая. Форма заявки не работает («Онлайн-отправка пока недоступна»), нет Метрики, нет страниц доставки/оплаты/контактов/о компании, нет реквизитов, контакт — личный gmail. В каталоге 38 товаров и 7 категорий, семантики под «габбро-диабаз», ступени, бордюры по видам нет.
- **kub-lesa.ru**: хорошая база (351 URL, Product+Offer на 275 карточках, Store с адресом и часами, страницы доставки и контактов, Метрика стоит). Проблемы: зеркало `www` отдаёт 200 вместо 301, `index.html` отдаёт дубль, нет og:image, нет реквизитов и отзывов, нет посадочных под размеры и «оптом», раздел «Крепёж» — 5 позиций «цена по запросу».

Без разработчика (владелец):

- фото товаров и объектов;
- частоты в Вордстате по §3;

Нужен доступ:
- **Яндекс.Вебмастер** — оба сайта (индексация, зеркало www у KL, ошибки разметки, запросы). Meta `yandex-verification` в коде нет ни на одном; подтверждение могло быть файлом или DNS — нет данных.
