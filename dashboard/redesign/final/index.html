Архитектура карта · v0.1

Связь на карте — возможный путь данных, а не факт выполнения. Свет бежит только по связи с реальным событием (результат не старше 15 мин); остальные связи статичны — «нет потока».

  • Работает
  • Внимание
  • Ошибка
  • Нет данных
  • поток по событию
  • нет потока

Цвет — по давности полезного результата, а не по «служба active». Зелёный только при доказательстве; без него — «не подтверждено». История хранится только в этом браузере.
