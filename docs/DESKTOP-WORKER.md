## Как запускать
1. `git pull` в `C:\Ilya-audit`.
2. Задачу записать в файл `worker-tasks\<имя>.md` (Цель / Контекст / Границы / «Разрешено владельцем:» если есть «да» / Готово, когда).
3. Запуск из своего терминала:
   - PowerShell: `cmd /c "C:\Ilya-audit\tools\claude-worker.cmd -f worker-tasks\<имя>.md"`
   - Git Bash: `cmd //c "C:\\Ilya-audit\\tools\\claude-worker.cmd -f worker-tasks\\<имя>.md"`
   Долгую задачу — в фоне; ждать завершения, не запускать второй раз.
4. Итог — в конце вывода и в `worker-logs\<время>.md`. Проверить факты (`git log -3`, файлы) и доложить владельцу.

## Если не запускается
- «Ключ пустой»/просит ключ — переменные не видны твоему процессу: перезапусти десктоп (переменные `setx` видны только новым процессам).
- Сообщение про «nested session / inside another Claude Code session» или ответ приходит от подписки, а не от шлюза —
  твой процесс передаёт исполнителю свои переменные (CLAUDECODE, ANTHROPIC_AUTH_TOKEN, ANTHROPIC_BASE_URL).
  Сообщи владельцу точный текст ошибки; обходной путь — владелец запускает команду из шага 3 сам в обычном `cmd`.
- 401/403 — ключ; 404 — адрес (ILYA_WORKER_BASE_URL); ошибка модели — ILYA_WORKER_MODEL.
