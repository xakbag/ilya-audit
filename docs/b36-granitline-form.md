## Выкладка — нужно «да» Ильи
1. Ящик-отправитель на домене (например `site@granitline.ru`) — создать в ispmanager reg.ru, плюс SPF `v=spf1 include:_spf.hosting.reg.ru ~all` (уточнить у reg.ru). Без этого письма вероятно уйдут в спам gmail.
2. `python sites/granitline-form/build-deploy.py apply <ящик>@granitline.ru` → запуск `steps/step106-gl-form-deploy.run.sh`: бэкап в `~/granitline-form-backup-<ts>/`, заливка index.php → конфиг (recipient прежний) → чанк. Проверки после: GET 405, чужой Origin 403, флаг в чанке.
3. Одна тестовая заявка Ильёй с сайта и проверка, что письмо дошло (нужна его проверка ящика). Критерий: письмо пришло, на сайте «Заявка принята».
- Откат (≤2 мин): залить 3 файла из бэкапа обратно (команды печатает скрипт). Кэш чанка у посетителей `max-age` 45 дней: при откате вернётся только серверная заглушка (503 → честная ошибка), ложного «успешно» не будет.
- Ограничение: чанк кэшируется 45 дней под тем же именем, у недавних посетителей форма останется выключенной до сброса кэша (новые посетители и реклама — сразу). Полное решение — пересборка сайта с новым хэшем чанка (нужен исходник Next.js).
