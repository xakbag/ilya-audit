## Топ-2 рекомендации (часть b)

### 1. `autoMemoryReclaim=gradual` + своя задача автозапуска WSL (по образцу distrod) — S1
Чужого кода нет: штатная настройка WSL и задача Планировщика Windows.
Пилот:
1. Только чтение: `wsl --version`, `schtasks /query /fo LIST /v | findstr /i wsl` (есть ли автозапуск), текущий `.wslconfig` (уже известен).
2. Подготовить (без применения): XML задачи «WSL при старте» (триггер «При запуске», задержка 30 с, «выполнять вне зависимости от входа», действие `wsl.exe -d Ubuntu-24.04 --exec /bin/true`) и дифф `.wslconfig`: `memory=14GB`, `autoMemoryReclaim=gradual`.
3. «Да» Ильи → импорт задачи (от администратора) → в окне S1: бэкап `.wslconfig`, правка, `wsl --shutdown`, старт; затем одна перезагрузка Windows без входа → проверка по SSH, что службы поднялись.
Критерий: после перезагрузки без входа `/health` 8771 отвечает ≤ 5 мин; через 2 ч работы buff/cache WSL заметно ниже 17 ГБ, свободно у Windows ≥ 8 ГБ вне игры.
Откат: удалить задачу; вернуть `.wslconfig.bak`, перезапустить WSL.
Нужно «да»: импорт задачи Планировщика, правка `.wslconfig`, перезапуск WSL и одна перезагрузка Windows.

### 2. Проверка восстановления бэкапа: `restic check --read-data-subset` + `restore-test.timer` — S7/D4
Чужого кода нет: команды уже установленного restic, шаблон check-таймера — идея из erikw/restic-automatic-backup-scheduler.
Пилот:
1. Локально написать в `infra-config/` юниты `restic-check.service/.timer` (ежедневно после 04:45, `--read-data-subset=$(date +%u)/7`) и `restore-test.service/.timer` (1-го числа: restore `*.sqlite` в `/tmp`, `PRAGMA integrity_check` и `count(*)` на копии, JSON-результат для доски, очистка).
2. Один ручной прогон restore-test по SSH (запись только в `/tmp`, живые базы не трогаются) — нужно «да».
3. «Да» → установка юнитов, `daemon-reload`, `enable --now` таймеров.
Критерий: на доске карточка «бэкап»: последний backup ≤ 26 ч, последний check ok, последняя проверка восстановления ≤ 31 дня ok.
Откат: `disable --now` таймеров, удалить юниты, `daemon-reload`.
Нужно «да»: ручной прогон restore в `/tmp`; установка двух таймеров.
