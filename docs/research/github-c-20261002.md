## Топ-2 рекомендации и план пилота

1. **chrono (`ru`) для дат в Доме 2** — S «Дом 2», ~3 ч.
   Пилот: скачать фиксированную версию chrono-node (ESM-сборку) локально в `house2/site/vendor/`, проверить хеш и отсутствие сетевых вызовов в коде; в `parseTaskInput` вызывать `chrono.ru.parse` первым, регулярки — запасным путём; тесты в `house2/tests/` на 30 фраз («в пятницу», «через 2 недели», «к 15 октября», «послезавтра утром»). Критерий: ≥ 90% фраз дают верную дату, существующие тесты не падают. Откат: убрать вызов chrono (регулярки остаются). Выкладка на хостинг — Илья.
2. **Защитный слой бизнес-агента ответов** (свой код по идеям llm-guard/PurpleLlama/rebuff) — S5/H6, ~5 ч.
   Пилот локально: модуль `sanitize_untrusted.py` (невидимые символы, HTML-комментарии, границы «данные», флаги подозрительных просьб) + набор 25 русских инъекций + проверка, что агент выдаёт только черновик. Сначала read-only на сервере подтвердить H6 (`systemctl cat ilya-business-partner@replies`, конфиг отправки). Критерий: 25/25 инъекций помечены, ни одной автоотправки. Деплой на сервер — по скиллу `server-deploy-step`, после «да».

Отдельно: закрепить версию в `npx ecc-agentshield@<версия> scan` (0,5 ч).
