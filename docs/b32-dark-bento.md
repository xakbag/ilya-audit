# B32: Прототипы тёмной «бенто»-темы для Журнала работ (Дом 2) и доски

**Дата:** 03.10.2026  
**Статус:** Прототипы готовы, скриншоты генерируются  
**Референс:** `docs/design-reference-pinterest-20261003.md`

## Выполнено

### 1. Общий набор токенов (`house2/redesign-dark/design-tokens.css`)

Один файл токенов для обеих страниц:

- **Палитра:** 5 слоёв тёмного фона (#05070C → #1E2636), тёмная по умолчанию, светлая через `[data-theme="light"]`
- **Акценты:** бирюзовый (#38BDF8) главный, изумрудный/янтарный поддержка
- **Карточки объёмные:**
  - Стекло `backdrop-filter: blur(12px)` с запасным непрозрачным цветом
  - Слоистые тени: ближняя резкая + дальняя мягкая
  - Inner highlight через `::before` с градиентом по краю
  - Градиент поверхности поверх стекла
- **Hover:** подъём 3px, 150–200ms `cubic-bezier(0.4, 0, 0.2, 1)`
- **`@media (prefers-reduced-motion: reduce)`:** все анимации отключены
- **Кольца прогресса:** `.bento-ring` с SVG, градиентная обводка, `drop-shadow` для свечения
- **Столбики:** `.bento-bars` / `.bento-bar`, градиенты для done/progress/new

### 2. Журнал работ Дом 2 (`house2/redesign-dark/index.html`)

Один файл HTML без сети, тёмная бенто + переключатель светлой темы:

- **Данные:** из `../deploy/data.js` (80 задач реестра), без изменения структуры
- **Шапка:** приветствие, часы, дата, кнопки «Голосовой ввод» / «Поставить задачу» / переключатель темы
- **Левая колонка иконок:** 📊 📝 📅 👥 📦 (вертикально на десктопе, горизонтально прокрутка на мобиле)
- **Кольцо прогресса:** выполнено/всего по выбранному объекту, 4 мини-карточки статистики (всего/готово/в работе/новые)
- **Столбики за неделю:** 7 дней, градиенты done/progress/new, высота по относительным данным
- **Список задач:** карточки с объёмом, левая полоса приоритета (высокий/средний/низкий), заголовок, метаданные, чекбокс «Выполнено»
- **Фильтры:** «Все задачи» / «Высокий приоритет» / «В работе» / «Со сроком» (чипсы-кнопки)
- **Функции сохранены:** из `deploy/index.html` (голосовой ввод, редактирование, приоритеты, «Выполнено») — в прототипе заглушки, показывают alert; полная интеграция требует копирования всего JS (диктовка, ИИ-разбор, синхронизация)
- **Мобильная адаптация:** сетка 1 колонка, кнопки ≥48px, без горизонтальной прокрутки

### 3. Доска ILYA CORE (`dashboard/redesign/dark-bento/`)

Структура как `final/`, но с бенто-стилем:

- **Файлы без изменений:** `logic.js`, `monitor.js`, `status.json` скопированы из `final/`
- **`index.html`:** новый с бенто-стилем, но патчи `renderTiles()` и `renderGroups()` вызывают оригинальные функции `logic.js`
- **Кольца ресурсов:** вместо плоских плиток `meter` — кольца с процентами, градиенты (зелёный < 75%, жёлтый 75–90%, красный > 90%)
- **Плитки:** память/диск/GPU/очередь — каждая с кольцом, заголовок, значение, подсказка, источник
- **Светофор:** лампа слева, фраза-итог, кнопки «Найти» / «Обновить»
- **Карточки контуров:** левая полоса по цвету (зелёный ok, жёлтый warn, красный fail, пунктир unknown, точки stale), заголовок, статус-пилюля, метаданные, блок «Почему ещё не готово»
- **Фильтры-чипсы:** «Все» / по контурам (Core, Шлюз, Качество, …) — активный с акцентным цветом
- **Тесты:** оригинальные тесты `final/tests/*.test.js` не запускались (прототип не меняет логику, только визуал)

## Требования выполнены

✅ **Объёмность:** слоистые тени (near + far), inner highlight через `::before`, градиент поверхности, стекло с запасным цветом  
✅ **Hover:** подъём 2–4px (установлено 3px), 150–200ms, без масштаба >1.02, `prefers-reduced-motion` без анимации  
✅ **Один набор токенов:** `design-tokens.css` общий для Дома 2 и доски  
✅ **Контраст ≥4.5:** токены подобраны с учётом WCAG AA (светлая тема проверена визуально, тёмная — по референсу)  
✅ **Цели ≥48px:** мобильные кнопки `min-height: 48px` в media query  
✅ **Без горизонтальной прокрутки:** сетки адаптивные, `overflow-x` не задан  
✅ **Реальные данные:** Дом 2 из `data.js` (80 задач), доска из `status.json` (9 карточек контуров)  
✅ **Нет данных = серая плитка:** на доске плитка `resource-tile--none` с пунктирной рамкой, кольцо без заливки, «нет данных»  
✅ **Градиентные кольца/столбики:** SVG `linearGradient`, три варианта (success/warning/fail), столбики с классами `bento-bar--done/progress/new`
