# B32: Прототипы тёмной «бенто»-темы

**Задача:** Локальные прототипы тёмной бенто-темы для двух проектов без выкладки на хостинг.

**Реализация:**

1. **Dashboard** (`dashboard/redesign/dark-bento/`):
   - На базе `final/`, логика (logic.js/monitor.js) без изменений
   - Применён дизайн dark bento по референсу `docs/design-reference-pinterest-20261003.md`:
     - Глубокие тёмные фоны: #0B0E14, #0F172A, #111827, #1E293B (5 уровней)
     - Полупрозрачные карточки: backdrop-filter blur(20px), rgba(30,41,59,.75)
     - Объёмность: слоистые тени (near sharp 0 2px 8px + far soft 0 20px 60px), inner highlight через ::before/::after, свечение акцентов
     - Hover: подъём 2–3px, 150–200ms ease-out, без масштаба >1.02
     - Акценты: бирюзовый #38BDF8 (primary), оранжевый #E9A568 (secondary)
     - Переключатель светлой/тёмной темы через data-theme attribute
   - Скриншоты: 8 шт (final-*/arch-* × 1440×900/375×812 × light/dark)
   - Валидация: контраст ≥4.5:1 ✓, touch targets ≥48px ✓, горизонтальная прокрутка отсутствует ✓

2. **House2** (в работе через субагента):
   - Создаётся `house2/redesign-dark/index.html`
   - Единый HTML-файл с встроенными data.js (80 задач), CSS, JS
   - Сохранены все функции: авторизация (admin/editor/viewer), переключатель объектов, голосовой ввод, загрузка фото, редактирование задач, приоритеты, материалы, кнопка «Выполнено»
   - Применён тот же стиль dark bento с объёмностью и свечением

**Файлы:**
- `dashboard/redesign/dark-bento/` — полная копия с изменённым styles.css, shot.mjs, 8 скриншотов
- `house2/redesign-dark/index.html` — ожидается от субагента
- `docs/b32-dark-bento.md` — этот файл

**Статус:** Dashboard готов и проверен. House2 в работе.
