# Как передать пакет другому ИИ

Прикрепите SERVER-CONTEXT.md и SERVER-SNAPSHOT.json либо весь ZIP, если ИИ умеет читать архивы.

Задание: провести независимый аудит описанной системы. Отделить подтверждённые факты от предположений. Найти причины остановки полезной работы, проверить архитектуру и предложить исправления в порядке приоритета. Для каждого вывода указать источник, дату, влияние, необходимые проверки, критерий готовности и откат. Недостающие сведения запросить, а не выдумывать.

## Доступ

Этот архив не выдаёт удалённый доступ. В нём нет паролей, токенов или приватных ключей.

Существующий административный маршрут через Tailscale и SSH проверен, но отдельная учётная запись аудитора не создана. Адрес 100.66.82.120 доступен только при подходящей сетевой авторизации; это не публичный адрес.

Для подключения внешнего исполнителя нужны его место запуска и публичный SSH-ключ, затем отдельная ограниченная учётная запись, правила доступа и проверка соединения. Не передавайте ему существующий административный приватный ключ.

ИИ без терминала и сетевых инструментов сможет изучить материалы, но не подключиться к серверу. На первом этапе аудит должен быть без изменения конфигурации. Публикация портов, перезапуск WSL и отключение защиты не требуются.

- SERVER-CONTEXT.md — цели, архитектура, данные, модели, проблемы, пути, доступ и критерии аудита; рабочие технические заметки.
- SERVER-SNAPSHOT.json — свежий обезличенный снимок служб, таймеров, очереди и тестирования.

Документ собран из наблюдений инструментами Codex. Оформление было делегировано бесплатному пулу FreeLLMAPI, но завершилось ошибками; результат модели в пакет не включён. Это подготовленный набор исходных данных, а не полностью отредактированный отчёт.
